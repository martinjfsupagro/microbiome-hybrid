# _etat/ — mémoire partagée du projet

La continuité du projet est portée par ces fichiers, pas par une conversation.

- `PROJET.md` — question, hypothèses, périmètre, conventions de nommage, chemins canoniques, outils.
- `DECISIONS.md` — journal daté antichronologique ; index qui **pointe** vers `docs/decision_*.md`.
- `DONNEES.md` — manifeste des jeux de données : chemin, provenance, md5 ou taille, statut, usages.
- `RESULTATS.md` — résultats validés, un par entrée, avec le script et les données qui les produisent.
- `A_FAIRE.md` — une section par type de session (Bibliographie, Analyse, Rédaction, Soumission, Autre)
  avec les passations : ce qui est attendu de qui, ce qui bloque, ce qui est prêt à consommer.

**Rituel** — en début de session : lire `PROJET.md` puis `A_FAIRE.md`, puis les fichiers utiles à la
tâche ; annoncer en trois lignes ce qu'on sait et ce qu'on va faire. En fin de session ou sur le mot
« clôture » : mettre à jour les fichiers concernés, réécrire sa section d'`A_FAIRE.md`, laisser une
note de passation de cinq lignes. Le texte complet du rituel est dans `INSTRUCTIONS_PROJET.md`.
Ce qui est inféré sans certitude reste marqué `[À CONFIRMER]`.
